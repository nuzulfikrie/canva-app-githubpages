Bagaimana mencipta laluan (pathway)

BM dahulu, kemudian English. Contoh utama: UASA Darjah 3. Contoh kedua: UPKK (6 subjek, 24 bab termasuk Set Kuiz, 36 pelajaran, 144 soalan — data sebenar).

Peranan: Administrator, Superadmin atau Guru. Hanya admin/superadmin boleh pautkan Pelan.
Dalam senarai Pathways, gunakan carian (cth. UASA atau UPKK) untuk menapis senarai kepada laluan yang relevan.

Bahasa Melayu

1. Buka Exam Pathways

  1. Sidebar: Administration › Akademi › Pathways. Guru boleh buka melalui Kurikulum › Pembina laluan.
  2. Halaman Exam Pathways menunjukkan tajuk, bilangan subjek dan soalan. Butang + New pathway.

2. Cipta laluan baharu (pilihan)

  1. Klik New pathway.
  2. Isi Name (wajib) dan Description (pilihan), kemudian Create.

3. Pembina laluan — UASA Darjah 3

  1. Buka UASA Darjah 3.
  2. Tab Pembina (aktif), Pelan, Bank soalan (cth. 432).
  3. Bahagian Pembina laluan: “Susun subjek, bab, dan pelajaran laluan ini.” Ringkasan: Subjek / Bab / Pelajaran / Soalan dipautkan. Butang Kembang semua / Kuncup semua.
  4. Tambah subjek (placeholder cth. Jawi) atau Pautkan subjek sedia ada → Pilih subjek → Buka subjek.

4. Subjek, bab dan pelajaran

  1. Buka subjek (cth. Matematik / Bahasa Melayu).
  2. Tambah bab / Tambah pelajaran. Nama baharu: Nama baharu → Simpan atau Batal.

5. Wiki guru & terbit

  1. Buka pelajaran (cth. Nilai Tempat Ribu, Ratus, Puluh dan Sa).
  2. Mode Sunting / Pratonton pelajar. Status Diterbitkan dengan tindakan Nyahterbit.
  3. Panel Bank soalan di kanan: + Add question, Cari soalan…. Bahagian Semak kefahaman menunjukkan soalan dipautkan.
  4. + Tambah pelajaran dalam pokok laluan untuk menambah lagi.

6. UPKK (contoh kedua)

  1. Laluan UPKK mempunyai 6 subjek (Akidah, Ibadah, Sirah, Adab, Jawi & Khat, Bahasa Arab).
  2. Setiap subjek ada bab kandungan serta bab Set Kuiz. Contoh pelajaran: Pengertian Iman dan Enam Perkara yang Wajib Diimani; contoh kuiz: Akidah — Set Kuiz 1.
  3. Gunakan hanya tajuk yang wujud dalam data semasa — jangan cipta kandungan UPKK yang tidak wujud.
Berkaitan: Set ujian (3a) · Bank soalan · ExamBuilder guru (3b)

English

Roles: Administrator, Superadmin, or Teacher (Guru). Only admin/superadmin can link a Plan (Pelan).
In the Pathways list, use search (e.g. UASA or UPKK) to filter to the pathways you need.

1. Open Exam Pathways

  1. Sidebar: Administration › Akademi › Pathways. Teachers can open via Kurikulum › Pembina laluan.
  2. The Exam Pathways page shows titles, subject counts, and question counts. Button: + New pathway. See Figure 1.

2. Create a new pathway (optional)

  1. Click New pathway.
  2. Fill Name (required) and Description (optional), then Create. See Figure 2.

3. Pathway builder — UASA Darjah 3

  1. Open UASA Darjah 3.
  2. Tabs: Pembina (active), Pelan, Bank soalan (e.g. 432).
  3. Pembina laluan section: “Arrange subjects, chapters, and lessons for this pathway.” Summary: Subjects / Chapters / Lessons / Linked questions. Buttons Kembang semua / Kuncup semua.
  4. Tambah subjek (placeholder cth. Jawi) or Pautkan subjek sedia ada → Pilih subjek → Buka subjek. See Figure 3.

4. Subjects, chapters, and lessons

  1. Open a subject (e.g. Mathematics / Bahasa Melayu).
  2. Tambah bab / Tambah pelajaran. New name: Nama baharu → Simpan or Batal. See Figure 4 and Figure 5.

5. Teacher wiki & publish

  1. Open a lesson (e.g. Nilai Tempat Ribu, Ratus, Puluh dan Sa).
  2. Modes Sunting / Pratonton pelajar. Status Diterbitkan with action Nyahterbit.
  3. Right-hand Bank soalan panel: + Add question, Cari soalan…. Semak kefahaman shows linked questions.
  4. Use + Tambah pelajaran in the pathway tree to add more. See Figure 6.

6. UPKK (second example)

  1. The UPKK pathway has 6 subjects (Akidah, Ibadah, Sirah, Adab, Jawi & Khat, Bahasa Arab).
  2. Each subject has content chapters plus a Set Kuiz chapter. Example lesson: Pengertian Iman dan Enam Perkara yang Wajib Diimani; example quiz: Akidah — Set Kuiz 1.
  3. Use only titles that exist in the current data — do not invent UPKK content.
