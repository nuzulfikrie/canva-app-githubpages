Bagaimana mencipta laluan (pathway)

BM dahulu, kemudian English. Contoh utama: UASA Darjah 3. Contoh kedua: UPKK (6 subjek, 24 bab termasuk Set Kuiz, 36 pelajaran, 144 soalan — data seed sebenar).

Peranan: Administrator, Superadmin atau Guru. Hanya admin/superadmin boleh pautkan Pelan.
Dalam senarai Pathways, gunakan carian (cth. UASA atau UPKK) supaya laluan ujian Laluan Dusk … / Laluan Runner … tidak kelihatan dalam skrin. Jangan padam laluan tersebut.

Bahasa Melayu

1. Buka Exam Pathways

  1. Sidebar: Administration › Akademi › Pathways. Guru boleh buka melalui Kurikulum › Pembina laluan.
  2. Halaman Exam Pathways menunjukkan tajuk, bilangan subjek dan soalan. Butang + New pathway.

2. Cipta laluan baharu (pilihan)

  1. Klik New pathway.
  2. Isi Name (wajib) dan Description (pilihan), kemudian Create.

3. Pembina laluan — UASA Darjah 3

  1. Buka UASA Darjah 3.
  2. Tab Pembina (aktif), Pelan, Bank soalan (cth. 432).
  3. Bahagian Pembina laluan: “Susun subjek, bab, dan pelajaran laluan ini.” Ringkasan: Subjek / Bab / Pelajaran / Soalan dipautkan. Butang Kembang semua / Kuncup semua.
  4. Tambah subjek (placeholder cth. Jawi) atau Pautkan subjek sedia ada → Pilih subjek → Buka subjek.

4. Subjek, bab dan pelajaran

  1. Buka subjek (cth. Matematik / Bahasa Melayu).
  2. Tambah bab / Tambah pelajaran. Nama baharu: Nama baharu → Simpan atau Batal.

5. Wiki guru & terbit

  1. Buka pelajaran (cth. Nilai Tempat Ribu, Ratus, Puluh dan Sa).
  2. Mode Sunting / Pratonton pelajar. Status Diterbitkan dengan tindakan Nyahterbit.
  3. Panel Bank soalan di kanan: + Add question, Cari soalan…. Bahagian Semak kefahaman menunjukkan soalan dipautkan.
  4. + Tambah pelajaran dalam pokok laluan untuk menambah lagi.

UPKK (contoh kedua)

Laluan UPKK mempunyai 6 subjek (Akidah, Ibadah, Sirah, Adab, Jawi & Khat, Bahasa Arab). Setiap subjek ada bab kandungan serta bab Set Kuiz. Contoh pelajaran: Pengertian Iman dan Enam Perkara yang Wajib Diimani; contoh kuiz: Akidah — Set Kuiz 1. Jangan cipta kandungan UPKK yang tidak wujud dalam seed.

English

Open Administration › Akademi › Pathways (teachers: Kurikulum › Pembina laluan). Filter the list so leftover Laluan Dusk / Laluan Runner rows stay out of screenshots — never delete them.

Use UASA Darjah 3 as the main walkthrough: Pembina tab, Tambah subjek / Pautkan subjek sedia ada, chapters and lessons, then the lesson wiki (Sunting, Diterbitkan / Nyahterbit, linked Semak kefahaman questions). UPKK is a second real pathway with Set Kuiz chapters — use only real seeded titles.
