Before you start

  • Everyone signs in with an account created by an administrator.
  • Administrators use the Administration sidebar (Identity, Plans, Akademi › Pathways / Questions, …).
  • Teachers and students use the portal menu (Utama, Bahan saya, Simulasi peperiksaan, …).
  • Labels mix English and Malay on screen (e.g. Padam, Simpan, Diterbitkan). Guides quote labels exactly as shown.
  • Set ujian (3a) and ExamBuilder bahan (3b) are different features — each guide links to the other.
